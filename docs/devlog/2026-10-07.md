## 변경 사항

### 1. Claude 스트리밍 채팅 (`98914d4`)
- Spring Boot 4 + Kotlin + JPA + Flyway + PostgreSQL 프로젝트 초기 구성 (`compose.yaml`로 로컬 Postgres)
- `V1__init.sql`: `conversations`, `messages`, `tasks`, `documents` 테이블 생성
- `POST /chat`: SSE로 Claude 응답을 스트리밍
  - 이벤트 순서: `meta`(conversationId) → `delta`(텍스트 조각) 반복 → `done`, 실패 시 `error`
  - 스트리밍은 가상 스레드에서 처리, `SseEmitter` 타임아웃 180초
  - 대화 기록을 DB에 저장하고 다음 요청 때 히스토리로 함께 전송
- `AnthropicConfig`: `anthropic.api-key`로 `AnthropicClient` 빈 등록

### 2. 인증, CORS, 대화 목록 (`c2609d9`)
- `WebConfig`
  - CORS 필터: `app.allowed-origins`(쉼표 구분)에 등록된 origin만 허용
  - 패스코드 필터: `X-App-Passcode` 헤더가 `app.passcode`와 다르면 `401 {"error":"unauthorized"}` (OPTIONS는 통과)
- `GET /conversations`: 최근 수정된 대화 50개
- `GET /conversations/{id}/messages`: 대화의 메시지 목록

### 3. 채팅 프롬프트 수정 + 문서 작성 작업 추가 (`8155eb3`)
- 시스템 프롬프트의 사용자 설명을 "백엔드/서버 개발자 직무 취업 준비, 2027년 2월 졸업 예정"으로 구체화
- 커밋 메시지에는 빠져 있지만 **Task 모듈 전체가 이 커밋에서 추가됨**
  - `POST /tasks`(202 Accepted), `GET /tasks`, `GET /tasks/{id}`, `GET /documents`, `GET /documents/{id}`
  - `TaskWorker`: 2초마다 `PENDING` 작업 하나를 `FOR UPDATE SKIP LOCKED`로 가져와 Claude로 마크다운 문서 작성 후 `documents`에 저장
  - 실패 시 최대 3회 재시도, 10분 넘게 `RUNNING`인 작업은 1분마다 복구(`recoverStale`)
  - `@EnableScheduling` 추가

### 4. Docker 배포 설정 (`bf32609`, `b0096cd`)
- 멀티 스테이지 `Dockerfile` (JDK 21로 `bootJar` 빌드 → JRE 21 이미지에서 실행), `.dockerignore` 추가
- 파일명을 `dockerfile` → `Dockerfile`로 수정
- 참고: 커밋 메시지는 "read PORT from env"지만 `application.yml`에는 `server.port: 8080`이 고정값으로 들어가 있다. 포트를 바꾸려면 `PORT`가 아니라 `SERVER_PORT` 환경변수를 써야 한다.

### 5. 사용자 프로필과 컨텍스트 주입 (`015fc8b`)
- `V2__profile.sql`: 단일 행(`id = 1`) `profile` 테이블 (`full_md`, `brief_md`)
- `GET /profile`, `PUT /profile`: 프로필 조회/수정
- `ContextService`
  - `forClaude()`: 현재 시각(한국) + 전체 프로필 + 최근 문서 제목 10개 → 채팅과 Task 시스템 프롬프트 뒤에 붙임
  - `forVoice()`: 현재 시각 + 요약 프로필 + 최근 문서 제목 5개 → `GET /context/voice`로 제공 (Gemini 음성 통화용)
- 채팅 시스템 프롬프트에서 하드코딩된 사용자 설명을 빼고 프로필을 참고하도록 변경
