- 로그인과 Bearer 인증
- 통화 기록 전송 (`POST /voice/calls`)
- 음성 도구 연결 (`GET /tools`, `POST /tools/{name}`)
- 나머지 화면
- 밝은 톤 디자인, 새 아이콘
- 기기에서 듣고 있다가 "수피"를 부르면 통화를 시작하는 방식

## CORS 확인

03:20에 Vercel 주소를 출처로 `POST /auth/login` preflight를 보냈다. 200이 왔고, 해당 출처와 `authorization`, `content-type` 헤더가 허용됐다.

11-07 기록에는 `ALLOWED_ORIGINS`가 기본값이라고 적었다. 하지만 이는 `localhost:3000`이 허용되는 것만 보고 추측한 것이었다. 그때 이미 설정돼 있었는지는 알 수 없다.
